# Rits File Viewer — Privacy Policy

**Effective date:** October 10, 2026

## 1. Overview

Rits File Viewer is an Android application developed by Vivid Creations Technologies. This policy explains how the app handles information when you use it.

## 2. No Document Transmission

Rits File Viewer processes and displays files locally on your device. The app does not transmit your files, document contents, or file data to our servers. The app does not require internet access.

## 3. No Analytics or Crash Reporting

The app does not use third-party analytics, advertising, or crash-reporting SDKs to track your activity or collect usage data.

## 4. Permissions

- **All-files access:** Allows the app to browse and manage files in shared storage, where you grant access.
- **Notifications:** Used to display progress and cancellation controls for long-running file operations when needed.
- **Foreground service:** Helps long-running operations continue while displaying an operation notification.
- **Legacy storage permissions:** Used on older Android versions where applicable.

The app uses these permissions to provide its file-management and viewing features.

## 5. Data Stored on Your Device

The app stores certain information locally, including:

- **Recent files:** Stores up to 50 local file paths. You can clear the list, and entries may be removed when files are moved, renamed, deleted, or no longer available.
- **Favorites:** Stores local file paths for files you mark as favorites. Entries are removed when applicable files are deleted.
- **Temporary files:** Temporary files created during file operations are cleaned up when operations finish or are cancelled, where applicable. Partial extraction files are cleaned up when extraction fails.
- **Settings:** Your app preferences are stored locally. Depending on your Android device settings, some preferences may be included in standard device backup.

Recent-file and favorite lists are excluded from standard cloud backup and device transfer. The app does not send this locally stored information to our servers.

## 6. Children’s Privacy

Rits File Viewer is a general-purpose file utility and is not specifically directed at children. The app does not knowingly collect personal information from children.

## 7. Changes to This Policy

This privacy policy may be updated when the app’s features or data practices change. The latest version will be published at this URL.
